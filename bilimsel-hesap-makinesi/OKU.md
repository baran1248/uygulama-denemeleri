# Ajantik Derleme Sablonu

Telefonda APK ureten mini proje sablonu. Yeni bir uygulama uretirken:

1. Bu klasoru `workspace/<proje-adi>` olarak kopyala (Turkce karakter kullanma).
2. `AndroidManifest.xml` icindeki `package` adini degistir (orn. com.ajantik.hesap).
3. `src/` altina Java kodunu yaz (Kotlin yok, sadece Java).
4. `res/values/strings.xml` icindeki uygulama adini degistir.
5. `bash build.sh` ile derle. Sonuc: `out/uygulama.apk`.
